LeonardX Manual Payment Workflow
1. User logs in and pays manually to configured account.
2. User submits amount, plan, and receipt URL/file reference.
3. Payment is PENDING.
4. ADMIN opens /admin and approves or rejects.
5. Approval activates Premium for 30 days.
For production, replace local receipt URLs with Cloudinary/S3 storage and configure secure ADMIN account creation.
